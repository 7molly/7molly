## 📅 Календарь выгрузки репозиториев

> Уникальная фишка: тепловая карта показывает, **в какие дни за последний год реально пушились/выгружались репозитории** (а не просто коммиты, как в стандартном GitHub-графике). Обновляется автоматически раз в сутки через GitHub Actions.

<p align="center">
  <img src="./assets/repo-calendar.svg" alt="Repo upload calendar" width="100%" />
</p>

<details>
<summary>⚙️ Как это работает / как настроить у себя</summary>

1. Скопируйте папки `scripts/` и `.github/workflows/` в свой профильный репозиторий `YOUR_GITHUB_USERNAME/YOUR_GITHUB_USERNAME` (специальный репозиторий, чей README попадает на страницу профиля).
2. В `scripts/generate_repo_calendar.py` не нужно ничего менять — username берётся из переменной окружения.
3. В настройках репозитория (`Settings → Secrets and variables → Actions → Variables`) добавьте переменную `GH_USERNAME` со значением вашего логина.
4. Workflow `.github/workflows/update-calendar.yml` запускается каждый день по расписанию и при пуше, дергает GitHub API, строит SVG-календарь в `assets/repo-calendar.svg` и коммитит изменения обратно.
5. Замените во всех местах `YOUR_GITHUB_USERNAME` и `YOUR_NAME` на свои данные.

</details>
